# Politique DM intelligente BYL

Objectif: ouvrir des conversations naturelles avec des leads qualifies, sans spam, sans automatisation agressive et sans comportement risquant de degrader la marque ou les comptes sociaux.

## Regle principale

Un DM n'est autorise que si le profil montre un signal d'interet clair ET correspond a la cible BYL.

Cibles:

- coach sportif;
- personal trainer;
- coach online;
- dieteticien;
- nutritionniste;
- salle de sport;
- studio fitness;
- structure de coaching.

## Signaux qui autorisent un DM

Un DM n'est jamais envoye uniquement parce qu'une personne a like un contenu. Le systeme calcule d'abord un score d'interet:

| Signal | Score |
| --- | ---: |
| Vue story | +1 |
| Clic profil | +2 |
| Commentaire | +3 |
| Reponse story | +4 |
| Visite site | +5 |
| Retour plusieurs jours | +6 |
| Coach identifie | +8 |
| Nutritionniste identifie | +8 |
| Salle identifiee | +10 |

DM autorise uniquement si:

- score >= 15;
- aucun DM precedent recent;
- le profil correspond a la cible BYL.

Les signaux forts restent prioritaires:

- commentaire qualifie sur un post BYL;
- reponse a une story;
- message entrant;
- clic repete vers le site si identifiable et autorise;
- demande d'information;
- interaction repetee sur plusieurs contenus.

Ou deux signaux moyens:

- sauvegarde ou partage visible si disponible;
- visite profil apres contenu;
- like recurrent;
- suivi recent du compte;
- profil clairement dans la cible.

## Interdictions

- DM massif;
- message identique envoye a beaucoup de comptes;
- scraping agressif;
- promesse de resultat garanti;
- faux compliment generique;
- insistance apres absence de reponse;
- relance automatique multiple;
- message a des particuliers non professionnels si aucun signal qualifie.

## Limites de volume

MVP:

- 5 a 10 premiers messages par jour maximum;
- 1 relance maximum;
- pas de relance avant 72h;
- arret immediat si la personne ne repond pas apres relance;
- aucun DM TikTok tant que l'app n'est pas validee et que les conditions plateforme ne sont pas claires.

## Structure du message

1. Contexte reel: reference a l'interaction ou au besoin observe.
2. Question courte: ouvrir la conversation.
3. Mention BYL naturelle.
4. Pas de lien dans le premier message sauf si la personne l'a demande.

Exemple coach:

```text
Salut [prenom], j'ai vu ton contenu sur le suivi client. Tu geres plutot tes programmes et relances avec un outil dedie ou encore avec un mix WhatsApp/Sheets ?
```

Exemple nutrition:

```text
Salut [prenom], ton approche nutrition a l'air tres structuree. Tu centralises deja menus, objectifs et retours clients dans un espace unique ou tu fais encore beaucoup a la main ?
```

Exemple club/studio:

```text
Bonjour [prenom], j'ai vu que vous gerez une structure fitness. Vous avez deja un outil central pour suivre clients, coachs, programmes et activite, ou c'est encore reparti sur plusieurs solutions ?
```

## Qualification avant essai gratuit

Si la personne repond:

1. comprendre son organisation actuelle;
2. identifier la friction principale;
3. proposer BYL comme solution pertinente;
4. envoyer le lien d'essai gratuit seulement si le besoin est confirme.

## Journal obligatoire

Chaque DM envoye doit etre journalise:

- date;
- plateforme;
- profil;
- type de cible;
- signal d'interet;
- message envoye;
- reponse;
- suite donnee;
- conversion eventuelle.

Le journal evite les doublons et permet d'apprendre sans spam.
